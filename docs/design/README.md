# Approved visual reference

These two files are the rendered options Ahmed chose from on 2026-11-20.
They are the visual spec for the face, not throwaway sketches — the
tablet app should match what is in them.

- `face-style.html` — the three eye treatments. **Chosen: A, pills.**
  Shows the wake-up (shut, then opening) and the idle blink, plus the
  six moods.
- `face-background.html` — the three background rules. **Chosen: B,
  true complement** — the field behind the eyes is the opposite hue at
  6-10% lightness.

Open either in a browser. Both are self-contained.

Two things they encode that are easy to lose in reimplementation:

- The two eyes blink at **slightly different intervals**. Synchronised
  blinking reads as mechanical.
- Mood is **shape plus colour, never colour alone**. Sad and sleepy are
  both cool-toned; what separates them is lid height and droop.
